# GreenShop React

Responsive plant-store demo built with React, Vite, React Router and CSS.

## Run locally
1. Install Node.js (LTS) if it is not installed.
2. Extract `greenshop-react.zip`.
3. Open the extracted `greenshop-react` folder in VS Code.
4. Open Terminal in VS Code and run:

```bash
npm install
npm run dev
```

5. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Features
- Home and shop pages, responsive layout
- Product search, categories, price filter and sorting
- Product detail page and quick-view modal
- Cart drawer and cart page with quantity controls/removal
- Checkout form and demo order confirmation
- Login/register demo form
- Blog cards and newsletter form
- Mobile navigation and responsive footer

Product images are loaded from Unsplash, so an internet connection is needed for them. Checkout/login are front-end demos only; no real payments or user accounts are processed.
